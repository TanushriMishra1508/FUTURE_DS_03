# FUTURE_DS_03

Marketing Funnel Analysis
Objective

Analyze marketing funnel data to identify conversion drop-offs, channel performance, and opportunities to improve lead-to-customer conversion.

Tools Used
Microsoft Excel / Google Sheets
Pivot Tables
Charts & Dashboard

Analysis Performed
Funnel Conversion Analysis
Converted vs Not Converted Analysis
Conversion by Contact Method
Conversion by Education Level
Channel Performance Analysis

Key Insights
Overall conversion rate: 7%
Paid Ads and Email showed the highest conversion rates.
Significant drop-off observed between Sign-Up and Customer stages.
Graduates and Postgraduates contributed the most conversions.

Visualizations
Funnel Chart
Pie Chart (Converted vs Not Converted)
Bar Chart (Contact Method Performance)
Bar Chart (Education Level Performance)

Outcome
Identified key conversion bottlenecks and provided recommendations to improve marketing effectiveness and customer conversion rates.
